No key is needed. These feeds are public, and they work in any country.

## Find a company's careers link

1. Go to the company's website and find **Careers**, **Jobs** or **Join us**, usually in the footer.
2. Open a page that lists open positions.
3. Copy the address and paste it into [Follow companies](/docs/guides/companies#follow-a-company).

RolePort recognises the hiring system from the link. A branded address, such as `careers.example.com`, also works if the page shows which system it uses.

## How to recognise each system

| Hiring system | Its addresses look like |
| --- | --- |
| Greenhouse | `job-boards.greenhouse.io/company` or `boards.greenhouse.io/company` |
| Lever | `jobs.lever.co/company` |
| Ashby | `jobs.ashbyhq.com/company` |
| SmartRecruiters | `careers.smartrecruiters.com/company` or `jobs.smartrecruiters.com/company` |
| Workable | `apply.workable.com/company` |
| Recruitee | `company.recruitee.com` |

## If a link doesn't work

- Open a page that lists jobs, not the company's home page. Try opening one job and copying that address.
- The company may use a system RolePort doesn't support yet, such as Workday. You can still [paste a job](/docs/guides/paste-a-job) one at a time.

Followed companies' feeds are cached for a few hours, and you can follow up to 100.
